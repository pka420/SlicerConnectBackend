Features
Built for medical imaging workflows
Everything your team needs to review and annotate together, without leaving 3D Slicer.

Live sync

Segmentations and scene state sync in real time between all connected users.

Self-hosted

Try our extension then Run the backend on your own server. Patient data never leaves your infrastructure.

REST + WS API

FastAPI backend with WebSocket support. Scriptable from Python or any HTTP client.

How it works
Up in three steps
01

Install extension

Add SlicerConnect from the 3D Slicer Extension Manager.

02

Point to server

Enter your server URL in the extension panel — connects to the FastAPI backend.

03

Create a session

Share the session ID with colleagues. They join and see your scene live.

Self-host the backend

Deploy the FastAPI server on your own machine or VM. Requires Python 3.10+.

$ git clone https://github.com/pka420/SlicerConnectBackend
$ setup env cat README.md
$ docker docker compose up -d
